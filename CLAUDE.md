## ProjectHub
This repo is tracked in ProjectHub as `nimelist`. Plans, scopes, tasks, decisions and memories live there — not in repo markdown.
- Context arrives at session start via `phub prime`. Run `phub digest` before non-trivial work.
- Never create plan/task/scope markdown files (no `docs/plans/`). Use `phub add`, `phub update`, `phub tree`.
- Claim with `phub start KEY`; hand off with `phub review KEY --pr URL` or `--evidence-file F`. Only the human runs `phub done`.
- Save durable lessons with `phub memory add` (`--global` if it applies to every project).
